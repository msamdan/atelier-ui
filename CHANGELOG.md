# Changelog

## 0.1.0 — 2026-09-28

### Added

- English Angular, Analog, and Taiga UI dashboard starter.
- Responsive dashboard, customer table, component gallery, theme studio, and settings examples.
- Extracted `atelier-theme` workspace package with CSS, LESS, ESM helpers, and TypeScript declarations.
- Theme normalization and isolated packed-consumer checks.
- MIT license, asset notices, contribution guidelines, issue templates, and CI checks.

### Status

Published as [atelier-theme@0.1.0](https://www.npmjs.com/package/atelier-theme/v/0.1.0). The source and starter are available on [GitHub](https://github.com/msamdan/atelier-ui). A hosted demo has not been published yet.
