# Roadmap

This is a working backlog, not a delivery commitment.

## Initial public release

- [x] English demo and documentation
- [x] Reusable local theme package
- [x] Light/dark themes, accents, and corner controls
- [x] Contribution guidance, license, and CI configuration
- [ ] Confirm the public repository and final npm package name
- [ ] Publish a hosted demo
- [ ] Complete a cross-browser and accessibility review
- [ ] Publish the first npm release

## Next iterations

- Theme JSON import and copyable integration snippets.
- More Taiga examples: select, date picker, popover, tabs, and pagination.
- Stronger keyboard navigation, focus management, and contrast checks.
- Test the package against additional Angular and Taiga versions.
- Visual regression coverage for both color modes.
- Separate reusable layout primitives from demo-only styles.

## Later, if useful

- Angular provider/service entry point for theme persistence.
- SSR support with a documented compatibility matrix.
- Additional starter layouts and application examples.
- Automated release notes and a maintainer-controlled npm publishing workflow.
